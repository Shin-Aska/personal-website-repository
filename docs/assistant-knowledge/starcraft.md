# StarCraft / BWAPI structured knowledge audit

Reviewed 2026-10-24. This audit covers `guides/StarcraftBWAPI.html`, the existing StarCraft overlay and adapter, and the existing production DOM record snapshot. The browser chat's scope is advanced-AI setup rather than a StarCraft campaign walkthrough. Technical identities, setup prerequisites, operating paths, errors, bot lineage, and documentation destinations supply its domain breadth.

## Source boundaries

The guide presents three distinct paths: SCHNAIL's separately supplied client/game, BWAILauncher against a separate Brood War 1.16.1 installation, and the integrated SCM map loaded natively in Remastered. A map archive is not the BWAPI development framework. Native Remastered map support does not establish that arbitrary BWAPI bots or launchers support Remastered. The shared runtime must keep those subjects apart.

There is an unresolved compatibility conflict within the guide. `#bwai-requirements` mentions original or Remastered while `#bwai-setup .text-yellow-700` requires a separate 1.16.1 installation. No indexed answer should certify general Remastered support for BWAILauncher. The official BWAILauncher repository URL linked by the guide was not retrievable through the research browser during this review; no external support conclusion was drawn.

The guide credits Steamhammer to Dave Churchill and links `https://github.com/davechurchill/Steamhammer`. The maintainer's Steamhammer page instead identifies a descendant of Churchill's UAlbertaBot and is signed Jay Scott. The existing guide's attribution must be labeled as a guide claim or replaced by a sourced conflict answer, not repeated as settled authorship. UAlbertaBot's official README and wiki name David Churchill; the guide additionally names Steve Gelly. The review does not establish the latter as a creator.

The guide's Java recommendation is Java JRE / Liberica JDK 21 LTS for SCHNAIL. It does not establish a universal Java version for StarCraft bots. PurpleWave's reviewed README specifies a 32-bit JDK 8 runtime connected to 32-bit BWAPI. These requirements must never be merged.

## Reviewed primary research

All external facts are concise paraphrases, tagged separately from guide facts, and checked on 2026-10-24. Repository READMEs can change; these notes describe the reviewed instructions, not compatibility certification or a play test.

- [BWAPI repository README](https://github.com/bwapi/bwapi): C++ framework for interacting with Brood War; restricted game-state visibility by default; quick start targets 1.16.1, an example AI module and Chaoslauncher. About 150 words across curated research facets, rather than copied documentation.
- [UAlbertaBot repository README](https://github.com/davechurchill/ualbertabot): David Churchill's competition bot; README reports maintenance stopped in early 2021 and documents BWAPI 4.4.0, VS2019, client executable behavior, and one-game execution limitation.
- [UAlbertaBot wiki](https://github.com/davechurchill/ualbertabot/wiki): bot written in C++ with BWAPI; bot architecture, configuration, worker/combat/pathfinding modification pages; SparCraft and BOSS relationships.
- [PurpleWave repository README](https://github.com/dgant/PurpleWave): Scala Brood War bot, all three races, a 32-bit JDK 8 runtime, Maven build, JAR execution and BWAPI data directories. Its build is an external alternative, not an added step for the SCHNAIL or map setup.
- [Steamhammer maintainer page](https://satirist.org/ai/starcraft/steamhammer/): a BWAPI bot descended from UAlbertaBot, MIT license, all three races, binary/configuration documentation and maintainer signature Jay Scott. This provides a reviewable alternative to the questionable guide repository link.
