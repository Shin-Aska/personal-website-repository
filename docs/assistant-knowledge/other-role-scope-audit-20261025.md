## Minimal reusable contract

1. Parse the request into **context, requested slot/action, conditions, and assertion mode** before routing. Context may anchor chapter, place, object or software. It must not become an independent unanswered question unless it actually requests information. Assertion mode separates static guide rule, conditional guide rule, reported current state and unverifiable current-state query. Carry every meaningful edition/source/numeric/material/negative condition.
2. Keep **topic owner, answer subject and answer role** separate. Use existing `answerRelations` and literal reviewed `answerBindings` for cross-owner eligibility. Add only a binding justified by a real mentioned object and role, such as the Pistol security-storage witness; do not promote all mentions to all capabilities. Where a generic location capability is insufficient, preserve the action condition (hiding before security vs acquisition) in the request/evidence contract.
3. Resolve a requested **person/item/place slot from one directed proof** with all evidence eligible; retain that returned slot for pronouns only after an actual complete answer. Required companion, provider, teacher and recipient must remain distinct. Retain coordinated objects as a set when the source explicitly names the set. Do not infer inverse edges, second-hop answers, current possession or party membership.
4. Give a supported typed factual request priority over consultation. “Recommend” in a request about avoiding a named hazard is method advice; consultation requires a ranking/choice act and criterion. A classifier label alone should not override an identified factual relation and source proof.
5. Evaluate conditional rules against **source conditions**, not whether the user has actually met them. Quoting “after login” does not set login state. A condition is answerable when the same proof explicitly supports its temporal interval and requested consequence; unsupported added conditions remain withheld.
6. Keep provenance attached to each claim through composition. A useful answer needs the full requested claim; strict citation precision is a separate check. Preserve frozen oracles and raw reports and record any equivalent locator adjudication separately.

The document text used by `knowledgeDocument` is subject/facet/aliases/text (`knowledge.js:31`); adding reviewed ownership metadata can preserve all encoded documents. This observation does not authorize embeddings, profile/head changes or new model execution.
